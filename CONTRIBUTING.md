# Contributing

Contributions, bug reports, and documentation improvements are welcome.

Before submitting a change:

1. Do not include real email addresses, internal hostnames, IP addresses, credentials, session keys, or production logs.
2. Test changes in a non-production Splunk environment.
3. Preserve `is_risky = true` unless there is a documented security review and a compelling reason to change it.
4. Include steps to reproduce bugs and describe the expected behavior.
5. Keep examples generic and use reserved example addresses such as `example.com`.

Please describe the Splunk version and Python runtime used when reporting compatibility issues. Never attach secrets or unredacted operational data.
